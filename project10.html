Project 10: Haunted House

I enetered the haunted house project with no ideas of what to do. I did know that I wanted to try something new, but I ended up just asking around what other people were doing. I decided that I wanted to work outside of the Lego kit, and that lead me to the idea of making some kind of screen originally for the project using LED strips and a microcontroller. I soon found out that the screen was to ambitous due to time constraints. Instead, I shifted gears and decided on making a spider with Griffin, so my part was giving it eyes and communication between the lego hub and Adafruit kb2040. I cut the LED Strips up to create two by two maxtrixes and soldered them together for each set of eyes, then I used the neopixel library to program the eyes to blink. I also programmed a means to communicate between the lego hub and microcontroller using a color sensor to detect the color of an LED that I would have ran up top. Although this was unnessessary for the final product. I also had a ultrasonic sensor to detect when somebody would have came close to the spider and that would have activited the lights to give a jumpscare effect, but too many people were already doing jumpscares so we decided against it.

Code:

                    
                        import time
import board
import neopixel

RED = (255, 0, 0)
OFF = (0, 0, 0)

right_eye = neopixel.NeoPixel(board.D8, 4, brightness=0.5, auto_write=False)
left_eye = neopixel.NeoPixel(board.D7, 4, brightness=0.5, auto_write=False)

def show_eyes(colors):
    reversed_colors = colors[::-1]       # left eye gets the list backwards
    for i in range(4):
        right_eye[i] = colors[i]
        left_eye[i] = reversed_colors[i]
    right_eye.show()
    left_eye.show()

OPEN = [RED, RED, RED, RED]     # all 4 lit
HALF = [OFF, OFF, RED, RED]     # bottom row only (squint)
CLOSED = [OFF, OFF, OFF, OFF]   # all off

def blink():
    show_eyes(HALF)
    time.sleep(0.08)
    show_eyes(CLOSED)
    time.sleep(0.12)
    show_eyes(HALF)
    time.sleep(0.08)
    show_eyes(OPEN)

show_eyes(OPEN)

while True:
    time.sleep(2.5)    # eyes stay open
    blink()
    time.sleep(0.4)
    blink()            # quick double blink
